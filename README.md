
# ATM Banking System in C++ (OOP)

This is a simple **ATM banking system** written in **C++ using Object-Oriented Programming (OOP)**.  
It was made like a student project, with simple code and friendly menu prompts.

## Features
- Create an account with a name, account number, PIN, and initial deposit.
- Login using account number and PIN.
- Check balance.
- Deposit money.
- Withdraw money.
- Transfer money between accounts.
- Show account information.
- Admin option to view all accounts.
